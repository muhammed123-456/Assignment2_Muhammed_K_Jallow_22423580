Project Note: CSS Grid & Flexbox Website

Project Type & Purpose: "The Global Echo" is a professional online magazine and news website designed for students, educators, and global readers seeking in-depth reporting on technology, culture, business, and the environment.

CSS Grid Usage: CSS Grid was utilized for major two-dimensional page structures, including the hero breaking story section (featuring a 2-column span for the main article and a sidebar stack) and the main article feed paired with the trending sidebar. Grid provides precise layout control across wide viewports without complex floats.

Flexbox Usage: Flexbox was implemented for one-dimensional alignment components, such as the top utility header bar, navigation menu items, author and date metadata tags inside article cards, and card footer button arrangements.

Responsive Design & Adaptations: To support small mobile screens without horizontal scrolling, fluid sizing, responsive CSS grid breakpoints (collapsing multi-column grids into single columns on mobile), and a mobile hamburger menu toggle were implemented.

Challenges & Solutions: A key challenge was ensuring that category filtering dynamically updated the grid layout smoothly without breaking alignment. This was successfully addressed using clean semantic class selectors and a lightweight JavaScript filtering function.
